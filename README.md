# むすび

このプロジェクトは、保護猫シェルターのスタッフさんと預かりボランティアさんの『毎日のお世話で手一杯で、猫の紹介まで手が回らない』という課題を、写真とスタッフさんのメモや預かりさんのLINEを貼るだけで、事実を盛らない紹介リールと投稿文ができるように変える、スマホのツール『むすび』です。一投稿でも多く発信することで、一匹でも多くの猫たちが新しいご家族と巡り会えるように。そんな思いで作りました。

Built with Claude: Japan 2026 ハッカソンの作品です。

## 審査員の方へ：試し方
1. スマホのブラウザ（iPhone なら Safari か Chrome）で、本番の https://hogoneko-card.pages.dev を開きます。
2. 架空の団体名を登録すると、すぐに試せます（必須は団体名だけです）。
3. ［新しい子を紹介］から、写真を選び、メモを貼るか書いて、［次へ］を押します。
4. 確認の画面で［物語の本文を書いてもらう］を押すと、本文と ✓ が出ます。

- 入れたデータは、そのスマホの中だけに残ります。サーバーには残りません。
- Claude を使う部分（本文を書く・確かめる）は、1日に使える回数に上限があります（みんなで使う分と、スマホ1台ごと）。上限になっても、決まった形の投稿文のままで動画を作れます。

## できること
写真・動画・メモを入れると、次のものができます。
- **メモから、紹介の本文**：スタッフさんのメモや預かりさんのLINEを貼ると、Claude が物語のような本文を書きます。
- **本文の ✓**：本文を1文ずつ確かめ、メモに根拠がある文に ✓ を付けます。根拠のない文には「⚠ メモにありません」と出し、人が［消す］か［本当です（残す）］を選びます。全部の文を確かめるまで、動画は作れません。✓ の文を押すと、メモのどこから来たかが光ります。
- **縦長のリール（1080×1920）と投稿文**：表紙・撮った動画・猫カード・ひとことカード・最後の1枚をつなげた動画を、スマホの中で作ります（動画を作れない機種では画像）。投稿文はボタン1つでコピーして、Instagram へ渡せます。ハッシュタグは1投稿5つまでです。
- **団体の色とロゴ**：登録した団体の色とロゴが、カードと動画に入ります。
- **次の譲渡会**：名前・日付・時間・場所を入れておくと、最後の1枚に小さく入ります。
- **猫の名簿**：一度紹介した子は名簿に残り、もう一度紹介するときは前の内容が入った状態で始められます。

## 事実を盛らない仕組み
- **書く Claude と、確かめる Claude** を分けています。書くのは Claude Sonnet 5.5、確かめるのは Claude Opus 5.5 です。
- 確かめる Claude には、メモと、入力した名前・「いいところ」、本文だけを渡します。文ごとに「メモのどこに書いてあるか」を引用で返してもらいます。「ある」と答えても引用がない文は、プログラムが根拠なしとして扱います。
- **測った結果**
  - 書く側：架空のメモ20件で本文を書いたところ、36文のうち、メモにない文は0でした（文ごとの判定は作者がしました）。
  - 確かめる側：わざと盛った文21文を混ぜた本文を3回ずつ確かめてもらい、63回すべてで盛った文を見つけました。
- **確かめ役は、Claude Haiku 5.5 と Claude Opus 5.5 を比べて、Opus 5.5 にしました。** Haiku 5.5 は安く速いのですが、63回のうち3回見逃しました。「盛った文を見逃さないこと」を一番に決めていたので、見逃しのなかった Opus 5.5 を選びました。
- AI に任せないこと：ハッシュタグの数、預かりさんのひとこと（書き換えずにそのまま載せます）、カードと動画づくり（AI を使わず、スマホの中で作ります）。最後は人が確かめます。

## 写真はスマホの外に出しません
- 写真と動画は、スマホの外に送りません。カードと動画は、スマホの中で作ります。
- AI に送るのは、メモの文字だけです。

## Claude の使い方
**ツールの中で**
- **書く役と確かめる役**：上の「事実を盛らない仕組み」のとおり、役目ごとに Claude を分けています。
- **測ってモデルを選んだこと**：確かめ役は、測った結果（見逃しの数・費用・時間）を見て選びました。測定用のメモは、頼み方の調整には使っていません。
- **引用の機能（citations）**：メモを1文ずつに区切って渡し、本文の文ごとにどの部分から来たかを返してもらいます。画面で文を押すとメモが光るのは、この引用を使っています。

**作るときに**
- **Claude Code の夜の自律作業**：作者が寝ている間や出かけている間、Claude Code が作業を進めました。決まりは次のとおりです。
  - GitHub・本番・Cloudflare の設定には触らない。上げるのは、作者がファイルの一覧を見て OK を出してから
  - Claude API の費用に、その夜の上限を決める（例：0.5ドルまで）
  - 1つの作業ごとに1つの記録（コミット）にして、朝に作者が入れるものを選べるようにする
  - 自動の確認を全部動かす（iPhone と Android の画面の幅のスクリーンショット、本文・名簿・動画の確認など）
  - 作った本人とは別のサブエージェントに見直しを頼み、重い指摘は直す
  - 見た目を変えたときは、前と後を並べた文書を作り、朝に Mac で開いておく
  - 上げる前に、キー・写真・動画が混ざっていないかを自動で確かめる仕組みも作りました
- **Claude.ai のチャットで毎日相談**：プロジェクトと引き継ぎメモを使って、決めることや次の頼み方を毎日相談しました。
- **デモ動画の曲**：デモ動画の曲も、Claude（チャット）がコードで作りました。
