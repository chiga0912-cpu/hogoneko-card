# 保護猫カード（仮）

保護猫シェルターのスタッフさんが、スマホで数分あれば、Instagramリール用の縦長素材（1080×1920）と投稿文を作れるツールです。
Built with Claude: Japan 2026 ハッカソンで制作中です。

## 今できること（11/2時点）
- シェルター情報、猫の情報を入力して、プレビュー、保存の画面まで進めます
- 投稿文のコピー

## これから
- カード画像（AIを使わず、スマホの中で作ります）
- AIで投稿文を整える＋入力にない話が混ざっていないかの確認

## 動かし方
```
npm install
npm run dev
```
